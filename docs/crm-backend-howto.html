Meow CRM - Backend How-To (Idiot Proof)

If you follow this exactly, it will work. No guesswork.

0) Basic Rule

1
Every API request needs a valid Token header.
2
Use JSON body for all POST requests.
3
All responses are JSON.

1) Core Setup (Do This First)

1
Log in and get a token.
POST /public/login
{ "name": "admin", "password": "your_password" }
2
Use the returned token in Token header for all requests.

2) Schemas (Custom Fields)

1
Get schemas.
GET /api/schemas
2
Update schema (example: Leads).
POST /api/schemas
{ "type": "lead", "schema": [ { "key":"lead-notes", "type":"textarea", "name":"Notes", "index":0 } ] }

3) Leads (Create + Update + Convert)

1
Create a lead.
POST /api/leads
{ "name": "Acme", "userId": "USER_ID", "attributes": { "lead-source": "Outbound" }, "contact": { "email": "a@acme.com", "phone": "123" } }
2
Update a lead.
POST /api/leads/LEAD_ID
{ "name": "Acme Updated", "attributes": { "lead-notes": "Hot lead" } }
3
Book meeting (auto converts to Account + Opportunity).
POST /api/leads/LEAD_ID/book
{ "startAt":"2026-02-07T09:00:00Z", "durationMinutes":30, "timeZone":"UTC", "summary":"Intro", "attendees":["a@acme.com"] }

4) Accounts + Opportunities

1
Create account.
POST /api/accounts
{ "name":"Acme", "userId":"USER_ID" }
2
Create opportunity (card).
POST /api/cards
{ "name":"Acme Deal", "userId":"USER_ID", "laneId":"LANE_ID", "amount":10000 }
3
Convert opportunity to account.
POST /api/cards/CARD_ID/convert-account

5) Customers

1
Create customer.
POST /api/customers
{ "name":"Acme Customer", "userId":"USER_ID", "contact": { "email":"a@acme.com" } }
2
Update customer.
POST /api/customers/CUSTOMER_ID
{ "attributes": { "plan":"Enterprise" } }

6) Roles + Permissions

1
Create role.
POST /api/roles
{ "name":"Sales Rep", "permissions": { "leads": { "browse": true, "read": true, "add": true, "edit": true, "delete": false } } }
2
Assign role to user.
POST /api/users/USER_ID
{ "roleId":"ROLE_ID" }

7) Google Workspace (Gmail)

1
Save integration settings (admin).
POST /api/teams/TEAM_ID/integration
{ "key":"google_workspace", "attributes": { "clientId":"...", "clientSecret":"...", "redirectUri":"https://domain/public/google-workspace/callback" } }
2
Get auth URL (user).
GET /api/integrations/google-workspace/auth-url
3
Send email via Gmail.
POST /api/emails
{ "to":["a@acme.com"], "subject":"Hello", "text":"Hi", "provider":"gmail" }
4
Sync inbound Gmail.
POST /api/emails/sync
{ "limit": 50 }

8) Mailgun (Campaigns)

1
Save integration settings.
POST /api/teams/TEAM_ID/integration
{ "key":"mailgun", "attributes": { "domain":"mg.example.com", "apiKey":"key-...", "sender":"Meow ", "region":"us" } }
2
Create campaign.
POST /api/campaigns
{ "name":"Launch", "audience": { "entity":"leads", "match":"all", "conditions":[] }, "template": { "subject":"Hi {{name}}", "html":"<p>Hello</p>" } }
3
Send now.
POST /api/campaigns/CAMPAIGN_ID/send

9) Telemarketer Settings (On/Off)

1
Save settings.
POST /api/teams/TEAM_ID/integration
{ "key":"telemarketer_settings", "attributes": { "enableQuickActions": true, "enableScripts": true, "enableCallTimer": true, "enableLeadQueue": true, "enableOutcomesDashboard": true, "enableAutoAdvance": true, "autoAdvanceOutcomesOnly": true, "autoAdvanceOutcomes": "Call back, No answer", "scriptsJson": "{...}" } }

10) Quick Troubleshooting

1
If you get 401, your Token is missing or expired.
2
If you get 404, check the URL and spelling.
3
If Google/Mailgun fails, verify integration settings and redirect URLs.
