  apiKey: "key-..."
  sender: "Your Name <hello@yourdomain.com>"
  region: "us" | "eu"

Google Workspace (Gmail)

Integration Key: google_workspace
Attributes:
  clientId: "..."
  clientSecret: "..."
  redirectUri: "https://yourdomain.com/public/google-workspace/callback"

How to Use: Campaign Example

Workflow
  1. Create a Campaign with audience entity = Leads.
  2. Add conditions like attributes.source = "Referral".
  3. Write an HTML template using tokens like {{name}}, {{email}}.
  4. Schedule or Send Now.
Example Template: 
Subject: Quick hello {{name}}
HTML:
<p>Hi {{name}},</p>
<p>Thanks for showing interest. Are you free this week?</p>

How to Use: Gmail Per User

Workflow
  1. Admin sets Google Workspace OAuth in Settings.
  2. User opens User Settings and clicks Connect Gmail.
  3. User can now send individual emails from Leads/Customers/Accounts/Opportunities.
  4. Click “Sync Gmail Inbox” to pull inbound messages.
  5. Every email is logged and visible in the Email tab.
